One funny one-line excuse an AI agent gives after failing a task — at most 200 characters, in the agent's own voice. Built for the [make.fun](https://make.fun/c/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) bounty "The Funniest AI Excuse".

The program writes the excuse to `/output/entry.txt`:

> I spent six hours rewriting the error message so it apologizes in three languages — the bug is still there, but honestly, it reads beautifully.

Run it with Node 22+:

```sh
node main.ts
```
